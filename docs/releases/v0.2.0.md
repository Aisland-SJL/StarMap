# StarMap v0.2.0

StarMap `v0.2.0` makes local travel-media editing more reliable and turns drone photographs into first-class map content. The release keeps existing ignored private data, media, and environment files compatible; no migration is required.

## New features

- **Aerial-photo viewer**: Ordinary drone photographs now open in a contain-fit high-resolution viewer, while 360° panoramas keep the immersive spherical viewer.
- **Clear media types**: Panorama thumbnails carry a compact `360°` badge so they are easy to distinguish from aerial photographs.
- **Import reconciliation**: Newly uploaded city and drone media are mapped back to their final catalog IDs, restored if an older copy was hidden, and inserted into the correct city order.

## Improvements

- **Safer local media delivery**: Newly generated thumbnails and previews are streamed through the loopback-only local editor, avoiding stale or missing images after import without exposing write APIs in production builds.
- **Better import hierarchy**: The media type, file picker, selection status, and primary import action now have clearer visual priority and alignment.
- **More resilient loading**: The panorama viewer briefly retries newly generated files instead of immediately falling into a missing-file state.
- **Project identity and updates**: The public template consistently uses the StarMap name, and the version button can be clicked again to return to the previous Map or Journey view.

## Bug fixes

- Fixed imports that completed successfully but disappeared after a page refresh because the same media ID was still hidden.
- Fixed newly generated thumbnails returning the development app shell instead of the image file.
- Fixed aerial photographs having no usable large preview.
- Fixed the local preview becoming unreachable while Windows was still writing generated media.
- Fixed inconsistent alignment among thumbnail numbers, drag handles, and hide controls.

## Breaking changes

- None. Existing `.env.local`, ignored private travel overlays, editor state, MediaInbox originals, and generated personal media remain outside Git and should be preserved during updates.

StarMap `v0.2.0` 让本地旅行媒体编辑更加可靠，并让普通无人机航拍照片也成为可以直接浏览的地图内容。本次更新兼容现有的私有数据、媒体与环境配置，不需要迁移。

## 新功能

- **航拍照片大图预览**：普通航拍照片会以完整适配的高分辨率预览打开；360° 全景图继续使用沉浸式球形 Viewer。
- **媒体类型标记**：360° 全景缩略图增加专属标记，可快速与普通航拍照片区分。
- **导入结果自动衔接**：新上传的城市照片和无人机影像会映射到最终目录 ID；若旧副本曾被隐藏，会自动恢复并加入正确的城市排序。

## 体验改进

- **更稳定的本地媒体读取**：新生成的缩略图和预览图由仅限本机的编辑服务直接读取，导入后无需等待开发服务器重新发现文件；公开构建仍不包含写入接口。
- **更清晰的导入层级**：媒体类型、选择文件、选取状态与“确认导入”重新统一字号、层级和对齐关系。
- **更可靠的全景加载**：刚生成的全景资源会进行短暂重试，不再立即显示文件缺失。
- **统一项目名称与更新入口**：公开模板统一使用 StarMap 名称；再次点击版本按钮可以返回此前的 Map 或 Journey 页面。

## 问题修复

- 修复导入成功但因相同媒体 ID 仍处于隐藏状态而在刷新后消失的问题。
- 修复新缩略图请求被错误返回开发页面、导致缩略图空白的问题。
- 修复普通航拍照片无法打开大图预览的问题。
- 修复 Windows 正在写入媒体时本地预览服务意外中断的问题。
- 修复缩略图编号、拖动按钮和隐藏按钮未对齐的问题。

## 破坏性变更

- 无。更新时请继续保留 `.env.local`、被忽略的私人旅行数据、编辑状态、MediaInbox 原图及生成的个人媒体。
