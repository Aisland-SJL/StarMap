# StarMap v0.3.0

StarMap `v0.3.0` separates personal travel content from the public source tree, strengthens multilingual city search, and makes local drone-media updates more reliable. Existing private files remain outside Git and must be preserved when updating.

## New features

- **Public and personal modes**: The same codebase now supports a neutral public template and an external personal profile without copying private content into the repository.
- **External private profile**: Personal configuration, travel records, MediaInbox originals, generated media, and editor state can live outside the Git working tree.
- **Resilient city search**: Cesium ion geocoding is preferred when configured, with a country-aware OpenStreetMap fallback and manual coordinates when online lookup is unavailable.
- **Release privacy gate**: Public releases can be checked from tracked files only, with explicit privacy and ignore-rule validation.

## Improvements

- **International place names**: City matching now handles Unicode composition, Latin diacritics, and equivalent localized names more consistently, including names such as São Miguel.
- **Safer permanent deletion**: Hidden media deletion resolves generated assets from the external private profile and validates all targets before removing anything.
- **More stable local editing**: Multi-file import and deletion operations are coalesced into one browser refresh instead of triggering several competing reloads.
- **Fresh media after import**: Private media modules are invalidated before the intentional refresh, so newly imported thumbnails and catalog entries appear immediately.
- **Documented collaboration ports**: Codex preview uses port 5173 and the DSH mirror uses port 5174 to avoid collisions.

## Bug fixes

- Fixed localized city searches that failed on traditional/simplified variants or accented characters.
- Fixed Cesium geocoding results being ignored when the service returned a bounding box instead of a point.
- Fixed permanent deletion requiring repeated attempts or refreshing the page several times.
- Fixed successful drone imports remaining invisible because the browser reused a stale private media module.
- Fixed local editor file changes causing redundant full-page refreshes during a single transaction.

## Privacy and migration

- Private photos, coordinates, travel JSON, `.env*` credentials, generated `*.local.json`, and `public/media/user/**` remain excluded from Git.
- No private data is included in this Release.
- Existing users should keep their ignored local data and credentials when updating. See the repository privacy and media-import documentation before moving personal files.

StarMap `v0.3.0` 将个人旅行内容从公开源码中彻底分离，同时强化多语言城市搜索，并提升本地无人机媒体导入与删除的稳定性。升级时请继续保留 Git 之外的私人文件。

## 新功能

- **公共版与个人版双模式**：同一套代码现在既能运行中立的公开模板，也能加载仓库外部的个人资料，不需要把私人内容复制进公开仓库。
- **外置私人资料层**：个人配置、旅行记录、MediaInbox 原图、生成媒体和编辑状态均可存放在 Git 工作区之外。
- **更可靠的城市搜索**：配置后优先使用 Cesium ion 地理编码，并提供限定国家的 OpenStreetMap 回退；联网不可用时仍可手动填写坐标。
- **发布隐私门禁**：公开发布只检查 Git 跟踪文件，同时验证隐私边界和关键 `.gitignore` 规则。

## 体验改进

- **国际地名兼容**：城市匹配更好地兼容 Unicode 组合形式、拉丁重音字符及本地化同名，例如 São Miguel。
- **更安全的彻底删除**：隐藏影像会从外置私人资料层定位生成资源，并在删除前统一验证全部目标。
- **更稳定的本地编辑**：一次导入或删除涉及的多次文件写入会合并成一次浏览器刷新，不再发生多次竞争刷新。
- **导入后立即显示新媒体**：主动刷新前会先使私人媒体缓存失效，新缩略图和目录项可以立即出现。
- **固定协作端口**：Codex 预览固定使用 5173，DSH 镜像固定使用 5174，避免双方抢占端口。

## 问题修复

- 修复繁简体变体、重音字符等本地化城市名称搜索失败的问题。
- 修复 Cesium 返回城市范围框而非单点时结果被忽略的问题。
- 修复彻底删除需要重复操作、并引发多次页面刷新的问题。
- 修复无人机影像已成功导入但因私人媒体模块缓存而暂时不可见的问题。
- 修复单次本地编辑事务期间文件变化触发多次整页刷新的问题。

## 隐私与迁移

- 私人照片、坐标、旅行 JSON、`.env*` 凭据、生成的 `*.local.json` 和 `public/media/user/**` 继续排除在 Git 之外。
- 本次 Release 不包含任何私人数据。
- 已有用户升级时应保留本地被忽略的数据与凭据；移动私人文件前请先阅读仓库中的隐私边界和媒体导入说明。
