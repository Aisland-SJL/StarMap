# StarMap v0.3.2

StarMap `v0.3.2` makes country management safer and keeps the country timeline in the correct newest-to-oldest order. This is a backward-compatible patch release with no private data or required migration.

## New features

- **Restore or permanently delete hidden countries**: Country editing now provides the same two-step cleanup pattern used by local media. Hidden countries can be restored from the left action or permanently removed from the right action.
- **Media-aware deletion guard**: A country may be permanently deleted only when none of its cities contains photos, panoramas, or aerial images. Hidden media still counts. If deletion is blocked, StarMap lists each affected city and its media count so users know exactly what to clean up first.

## Improvements

- **Newest visits stay on top**: After a country is added, StarMap compares the latest known visit date for every country and places the new entry in the newest-to-oldest timeline.
- **Stable ordering when dates match**: Countries with the same date, or without a comparable date, keep their existing relative order. Manual drag-and-drop ordering remains available afterward.
- **No automatic media cascade**: Permanently deleting a country never deletes photos or source originals automatically. Users must explicitly remove city media before the country can be deleted.

## Bug fixes

- Fixed newly added countries always appearing at the top even when their visit date belonged farther down the timeline.
- Fixed hidden countries having only a restore action and no guarded permanent-delete path.

## Breaking changes

- None. Existing external private profiles, travel records, media catalogs, MediaInbox originals, and local credentials remain compatible and must stay outside Git.

StarMap `v0.3.2` 让国家管理更加安全，并确保国家时间线始终按“上新下旧”排列。本次为向后兼容的补丁版本，不包含私人数据，也不需要迁移。

## 新功能

- **恢复或彻底删除隐藏国家**：国家编辑现在采用与本地媒体一致的双操作。左侧可以恢复隐藏国家，右侧可以永久删除。
- **媒体安全拦截**：只有当一个国家下的所有城市都不存在普通照片、360° 全景或航拍影像时，才允许永久删除。已隐藏但尚未彻底删除的媒体同样会触发拦截；系统会列出仍有媒体的城市和数量，方便用户逐城处理。

## 体验改进

- **最近到访国家自动置顶**：新增国家后，StarMap 会比较所有国家最近一次到访日期，并按新到旧重新定位。
- **相同日期保持稳定**：日期相同或缺少可比较日期时，维持原有相对顺序；完成自动定位后，用户仍可继续手动拖动排序。
- **不会自动级联删除媒体**：永久删除国家时不会顺带删除照片或投递箱原图。用户必须先在相应城市中明确完成媒体删除。

## 问题修复

- 修复新增国家无论日期新旧都固定出现在最上方的问题。
- 修复隐藏国家只有恢复操作、没有安全永久删除入口的问题。

## 破坏性变更

- 无。现有外置私人资料层、旅行记录、媒体目录、MediaInbox 原图及本地凭据继续兼容，并且必须保留在 Git 之外。
