# StarMap v0.3.1

StarMap `v0.3.1` makes local media cleanup consistent, keeps the current travel context across editor refreshes, and improves the in-app Release center. This is a backward-compatible patch release with no private data or required migration.

## Improvements

- **Refresh continuity**: Local editor refreshes now return to the selected country, city, page, zoom level, sidebar state, Journey view, and active drone-media context instead of resetting to the initial globe.
- **Clearer Release center**: Update Guide and Version Notes now share the first row, while the longer Update Announcement uses a full-width row below them.
- **Rendered release notes**: GitHub Release Markdown now renders headings, emphasis, lists, links, quotes, code, and GFM tables instead of exposing formatting characters.
- **No map startup penalty**: The Markdown renderer loads only when the Release page opens, keeping it out of the initial map bundle.

## Bug fixes

- Added Restore and Permanent Delete controls to City Photos, matching the drone-media editor.
- Fixed newly hidden City Photos requiring a second visit before permanent deletion could run.
- Fixed newly hidden drone media requiring an extra click on the editor checkmark before permanent deletion.
- Unified City Photos and drone-media deletion into one guarded local endpoint that validates hidden state, city ownership, source originals, and generated output paths before deleting.

## Breaking changes

- None. Existing external private profiles, ignored travel data, MediaInbox originals, generated media, and local credentials remain compatible and must stay outside Git.

StarMap `v0.3.1` 统一了本地媒体清理流程，让编辑器刷新后继续停留在原来的旅行位置，并完善应用内版本更新中心。本次为向后兼容的补丁版本，不包含私人数据，也不需要迁移。

## 体验改进

- **刷新后保持上下文**：本地编辑触发刷新后，会恢复此前选中的国家、城市、页面、缩放级别、侧栏状态、Journey 视图和无人机媒体上下文，不再回到初始地球。
- **更新中心布局更清晰**：“更新指南”和“版本说明”位于第一行；篇幅较长的“更新公告”在下方独占一整行。
- **更新公告支持 Markdown**：GitHub Release 中的标题、加粗、列表、链接、引用、代码和 GFM 表格会正常渲染，不再显示格式符号。
- **不拖慢地图首屏**：Markdown 解析器仅在打开版本更新页时加载，不进入地图初始包。

## 问题修复

- City Photos 增加与无人机影像一致的“恢复隐藏”和“彻底删除”操作。
- 修复 City Photos 刚隐藏后必须再次进入，才能永久删除的问题。
- 修复无人机影像永久删除前还要额外点击编辑器对号的问题。
- City Photos 与无人机影像统一使用受控删除接口；删除前会检查隐藏状态、所属城市、投递箱原图和生成目录，避免误删或越界。

## 破坏性变更

- 无。现有外置私人资料层、被忽略的旅行数据、MediaInbox 原图、生成媒体及本地凭据继续兼容，并且必须保留在 Git 之外。
